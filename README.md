## 3. Описание приложения

Bugs_Android — мобильная игра, в которой пользователь управляет игровым процессом, нажимая на появляющихся на экране жуков.

В приложении реализованы:
- регистрация и выбор игроков;
- настройка сложности и параметров игры;
- игровой процесс с несколькими видами жуков;
- начисление очков за попадания и вычитание очков при промахе;
- бонусный золотой жук (начисление очков пропорционально курсу золота в ЦБ РФ);
- подсчёт попаданий, промахов и точности;
- звуковое сопровождение;
- управление с использованием датчика наклона;
- мультитач-управление;
- тактильная обратная связь;
- локальный турнирный режим;
- сохранение результатов и истории турниров;
- таблица рекордов;
- виджет с отображением курса золота.

## 4. Турнирный режим

В приложении предусмотрен локальный турнирный режим, в котором несколько игроков участвуют в последовательных игровых раундах на одном устройстве.

Реализованы:
- добавление участников турнира;
- последовательное проведение раундов;
- сохранение результатов каждого участника;
- формирование итоговой таблицы результатов;
- определение мест участников на основании игровых результатов;
- сохранение истории завершённых турниров;
- сохранение результатов удалённых игроков с соответствующей отметкой.

## 5. Мультитач и тактильная обратная связь

В игровом процессе предусмотрена обработка нескольких одновременных касаний экрана.

Для повышения удобства игры реализована тактильная обратная связь:
- отдельная вибрация при попадании по жуку;
- отдельная вибрация при промахе;
- отдельная вибрация при нажатии на бонус.

Таким образом, пользователь получает физическую обратную связь в зависимости от результата взаимодействия с игровыми объектами.

## 6. Используемые технологии

- **Kotlin** — основной язык программирования.
- **Jetpack Compose** — создание игрового интерфейса и отдельных экранов приложения.
- **XML** — описание разметки экранов, элементов интерфейса и конфигурационных ресурсов Android.
- **Room** — локальное хранение игровых результатов и истории турниров.
- **Koin** — внедрение зависимостей.
- **ViewModel** — управление и сохранение состояния экранов.
- **Android SDK** — разработка Android-приложения.
- **SharedPreferences** — хранение настроек игры.
- **SensorManager** — работа с датчиками устройства.
- **Vibrator** — реализация тактильной обратной связи.

## 7. Инструкция по запуску

1. Установить Android Studio.
2. Открыть проект Bugs_Android в Android Studio.
3. Дождаться завершения синхронизации Gradle.
4. Подключить Android-устройство с включённой отладкой и установкой по USB либо запустить эмулятор.
5. Выбрать конфигурацию запуска `app`.
6. Нажать **Run**.
7. Дождаться установки и запуска приложения.

## 8. Тестирование

Для проверки работы хранения данных созданы инструментальные тесты `TournamentResultDaoTest`.

Проверяются:
- сохранение результатов турнира и сортировка по количеству очков;
- сохранение результатов удалённого игрока с отметкой `isDeleted`;
- формирование истории турниров с подсчётом количества участников и лучшего результата.
